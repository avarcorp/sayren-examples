# 02 브랜드

근거 문서: `01-research.md`의 차별점 D1–D5.

## 이름

**셔터점검소** (영문 표기 SHUTTER CHECK)

- 가칭 「필름 카메라 상점」은 품목만 말하고 차별점을 말하지 않는다.
- 「점검소」는 모든 카메라를 등록 전에 점검하고 점검표를 공개한다는 약속(D2)을 이름에 담는다. 「셔터」는 점검 첫 항목이자 필름 카메라를 바로 떠올리게 하는 부품이다.
- 상점 정보의 상점 이름(`name`)을 이 이름으로 바꾼다. 셀러가 다른 이름을 원하면 스테이징 검토에서 바꾼다.

## 말투

| 항목 | 기준 | 연결 차별점 |
|---|---|---|
| 문체 | 구매자 문구는 짧은 해요체(「~해요」「~해 주세요」). 질문은 「~나요?」. 버튼·라벨·상태값·표 머리는 명사구. 이용약관·개인정보처리방침만 합니다체 | — |
| 길이 | 한 줄 문구(라벨, 도움말, 자리 표시, 알림, 띠 공지)는 390px 한 줄(약 22자). 문장은 두 문장까지. 섹션 제목은 2–5단어 명사구 | — |
| 한 번만 | 보증·점검·배송·반품 약속은 상품 상세 안내 섹션과 `/help`에만 둔다. 띠 공지는 그중 하나를 한 줄로 | D1, D4 |
| 근거 | 형용사 대신 점검 결과와 수치로 말한다. 「상태 최상」 대신 「셔터 1/1000–1초 정상, 노출계 ±1/3스톱」 | D2 |
| 약속 | 보증·교환 조건을 숫자로 적는다. 「6개월 무상 수리」「7일 안 교환·환불」 | D1, D4 |
| 등급 | A급·B급 두 단어만 쓴다. 「민트」「S급」 같은 말은 쓰지 않는다 | D3 |
| 판매 완료 | 팔린 카메라를 숨기지 않고 「판매 완료」로 적는다 | D5 |

예시 문구(화면에 그대로 붙이지 않는다):
- 섹션 제목: 「판매 중인 카메라」
- 빈 목록: 「지금 판매 중인 카메라가 없어요」
- 오류: 「주문을 찾을 수 없어요. 입력한 정보를 확인해 주세요.」
- 품절 상태값: 「판매 완료」

## 로고 방향

- 글자 로고. Pretendard Bold로 「셔터점검소」를 쓰고, 앞에 필름 오렌지(`#D9531E`) 테두리의 작은 정사각형 안에 점 하나를 둔다(조리개·셔터 구멍을 줄인 표시, 점검 통과 표시와 같은 모양). D2의 점검 통과 표시와 같은 기호라 로고와 점검표가 하나로 읽힌다.
- 서체는 Pretendard 하나이고 별도 디스플레이 서체를 쓰지 않는다(rule 8).
- 헤더에서는 높이 20px 글자 로고, 모바일에서도 같은 형태를 쓴다. 로고 이미지는 만들지 않고 코드(텍스트 + CSS 테두리)로 그린다.
