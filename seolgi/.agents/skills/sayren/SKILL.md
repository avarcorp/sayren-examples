# sayren skills

The sayren skills are maintained centrally and change without updating this project.
Do not rely on memory or earlier copies. Load them at the start of each task.
1. List the skills (name and when to use each):
   `npx -y sayren@latest skill list`
2. Read every skill that matches the task, in full, and follow it:
   `npx -y sayren@latest skill <name>`

If the sayren MCP server is connected, the tools `list_skills` and `get_skill` return the same content.

Follow the project's `CLAUDE.md` first. The skills add the sayren-specific details.
